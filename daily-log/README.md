# 🗓️ Daily Prep Log

One short entry per study day — what you covered, how confident you feel, and what to revisit. This is how "daily preparation" actually compounds: it surfaces weak spots and tracks momentum.

## How to use

1. Copy [TEMPLATE.md](TEMPLATE.md) → `daily-log/YYYY-MM-DD.md`.
2. Fill it in (2–5 minutes) after the day's [plan](../STUDY-PLAN.md) task.
3. Add a row to the table below.
4. Commit.
