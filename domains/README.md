# 📚 Domain Study Guides

One guide per exam domain. Each has: **key concepts**, **what you must be able to do**, **resources**, and **self-check questions**. Study them in the order the [plan](../STUDY-PLAN.md) schedules (by weight), not necessarily 1→5.

| # | Domain | Weight | Guide |
| - | ------ | :----: | ----- |
| 1 | Agentic Architecture & Orchestration | **27%** | [01-agentic-architecture-orchestration.md](01-agentic-architecture-orchestration.md) |
| 2 | Claude Code Configuration & Workflows | **20%** | [02-claude-code-config-workflows.md](02-claude-code-config-workflows.md) |
| 3 | Prompt Engineering & Structured Output | **20%** | [03-prompt-engineering-structured-output.md](03-prompt-engineering-structured-output.md) |
| 4 | Tool Design & MCP Integration | **18%** | [04-tool-design-mcp.md](04-tool-design-mcp.md) |
| 5 | Context Management & Reliability | **15%** | [05-context-management-reliability.md](05-context-management-reliability.md) |

> Weights add to 100%. Spend your time proportionally — Domain 1 is worth nearly double Domain 5.

**How to use a guide:** read it, turn the *"must be able to"* bullets into flashcards, then answer the *self-check* questions from memory. If you can't, re-study that sub-topic and log it.
